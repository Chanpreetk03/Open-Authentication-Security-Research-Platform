# Security Policy

## Scope

This project is a local-first authentication protocol workbench and sandbox. Vulnerable scenarios use synthetic targets and data. They are not permission to test unrelated systems.

## Reporting a vulnerability

Please do not disclose a vulnerability in this repository, its dependencies, a protocol pack, or a scenario runner in a public issue before maintainers have had an opportunity to assess it. Report privately through the repository's GitHub Security Advisories feature. Include the affected commit/version, reproduction steps, impact, and any safe proof-of-concept details.

## Safety expectations

- Do not include real credentials, access tokens, private keys, or personal data in reports.
- Do not test project infrastructure or third-party systems without explicit authorization.
- Treat a sandbox escape, secret leak, unsafe external-target behavior, or cross-scenario access as high-priority.

This policy will be updated with supported release and response-time commitments if the project begins distributing releases or operating hosted infrastructure.
