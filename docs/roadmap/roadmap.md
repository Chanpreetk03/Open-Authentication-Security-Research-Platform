# Roadmap

1. Define the MVP around three protocol/security modules and lab isolation.
2. Build the local-first Authentication Lab foundation.
3. Build Protocol Studio tools for OAuth/OIDC, JWT, and request inspection.
4. Add the Cybersecurity Principles Academy with attack-and-defense exercises.
5. Add SAML, LDAP, Kerberos, MFA, and passkey modules incrementally.
6. Evolve the reference identity engine only where labs and Studio require it.
7. Reassess hosted and production-oriented capabilities after user validation.
