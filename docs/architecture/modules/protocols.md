# Protocol Packs

Protocol packs are the product's primary domain modules. Each pack owns its protocol-specific wire formats, actor/state behavior, validation, supported profiles, security scenarios, and explanations.

The shared platform supplies collections, scenario lifecycle, resource/capability controls, trace envelopes, redaction, reports, and reset. See the [protocol pack architecture](../protocol-lab-architecture.md) and [protocol catalog](../../protocols/README.md).
