# Database Design

The schema is not finalized. Likely identity-domain entities include identity,
credential, session, application, OAuth client, role, permission, policy,
group, membership, federation configuration, external identity, audit event,
and API-key/token metadata.

Before finalizing the schema, decide tenant isolation, primary and immutable
identifiers, external identifiers, soft deletion, audit retention, token
storage, indexing, and consistency requirements.
