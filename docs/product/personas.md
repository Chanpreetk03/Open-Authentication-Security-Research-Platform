# Personas

## Student

Needs a safe, understandable environment for learning authentication protocols,
cybersecurity principles, and system design.

## Developer

Needs protocol inspectors, flow visualizations, configuration guidance, and
repeatable integration test cases.

## Security engineer

Needs isolated attack simulations, vulnerable/secure comparisons, and tools to
validate authentication configurations and mitigations.

## Architect or educator

Needs clear explanations of trust boundaries, security principles, tradeoffs,
and repeatable labs for teaching or design review.
