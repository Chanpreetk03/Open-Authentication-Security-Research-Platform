# Learning Modules

Learning content is attached to protocol packs and scenarios. A module connects protocol behavior to a controlled failure, mitigation, and evidence; it is not a separate identity platform subsystem.

## Current module

- [Defense in Depth: OAuth State and PKCE](defense-in-depth-oauth.md)

This exercise reuses deterministic OAuth traces. It does not attack an external provider or authenticate real users. The broader product workflow is described in the [product vision](../product/product-vision.md).
