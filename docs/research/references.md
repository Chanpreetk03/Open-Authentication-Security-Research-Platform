# Authoritative References

Protocol packs use their owning standards and current best-practice documents as the source of truth. Maintain protocol-specific reference lists with each pack and record which version/profile a test implements.

Reference families include OAuth 2.0 security, OpenID Connect, JWT/JWS/JWE, SAML, LDAP, Kerberos, WebAuthn, TLS/PKI, cryptographic algorithm registries, and safe sandbox execution.

The [workbench and sandbox research](auth-protocol-workbench-and-sandbox.md) records the sources that inform the current product plan. Do not treat learning notes or synthetic scenarios as authoritative protocol specifications.
